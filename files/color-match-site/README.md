# 인덕션 컬러 매칭 서비스

정적 웹 서비스입니다. GitHub Pages 등 정적 호스팅에 올리면 https 주소가 생깁니다.

## 파일 (QR에 넣는 주소)
- `online.html`  : **온라인 PC·MO(반응형)**. 직원 추천 조합 영역이 보이지 않습니다.
  - 예: `https://주소/online.html` (온라인 상세페이지 버튼, 제품 옆 QR)
- `dealer.html`  : **대리점 태블릿**. 직원 추천 조합 영역이 추가로 보이고, 공유하기 버튼이 크게 표시됩니다.
  - 예: `https://주소/dealer.html` (대리점 전용 QR)
- `index.html`   : 두 용도를 함께 담은 시연용. 주소 뒤에 `?ch=online` 또는 `?ch=dealer`, `&demo=1`을 붙여 전환해 볼 수 있습니다.
- 공통: `?model=m1` 을 붙이면 해당 모델이 선택된 채로 열립니다. (예: `online.html?model=m1`)

## 공유하기
위쪽 "공유하기" 버튼을 누르면 팝업이 열리고, "리포트 이미지로 보내기"를 누르면
선택한 조합(상판·하부장·벽면 + 화이트·블랙 인덕션)을 담은 **리포트 이미지(PNG) 한 장**이 내려받아집니다.
- 이미지는 사용하는 기기 안에서 만들어져 서버나 API 비용이 들지 않습니다.
- 내려받은 이미지는 카톡·문자 등으로 고객에게 보내면 됩니다.

## 설정 (각 html 파일 안)
- `BACK_URL` : 온라인 상세페이지 주소 (비워 두면 이전 페이지로 이동)
- `SHARE_BASE` : 공유 링크 기본 주소

※ 갤러리 사진은 AI로 생성된 연출 이미지입니다. 사용 권한을 확인한 뒤 공개하세요.
